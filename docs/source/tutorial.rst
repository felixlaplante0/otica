Tutorial
========

The canonical, pre-executed tutorial notebook lives in
``../examples/tutorial.ipynb`` relative to the repository root.

`Open the tutorial notebook on GitHub <https://github.com/felixlaplante0/otica/blob/main/examples/tutorial.ipynb>`_.

The notebook generates independent non-Gaussian sources, mixes them linearly,
and recovers the sources with :class:`otica.model.OTICA`. It also aligns the ICA
permutation and sign ambiguities, reports the Amari index, and plots true and
recovered signals using the OTICA palette.
